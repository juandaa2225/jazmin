# Perfil web para psicóloga

Sitio estático y modular con un diseño profesional, minimalista y sobrio.

## Estructura

- `index.html`: estructura y secciones de la web.
- `styles/main.css`: estilos globales y responsivos.
- `scripts/main.js`: datos provisionales editables para actualizar contenido real fácilmente.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Cuando tengas la información real, edita el objeto `profile` en `scripts/main.js`.
3. (Opcional) Ajusta servicios, enfoque y contacto en `index.html`.
